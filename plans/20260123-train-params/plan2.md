# Plan: Change ekg_train to Output Config Struct

## Problem
`ekg_train.c` outputs `#define` macros, but `EKG_DEFAULT_CONFIG` has hardcoded values, so the output can't be used directly.

## Solution
Modify `write_best_config_header()` in `ekg_train.c` to output a config struct instead of `#define` macros.

## Changes to `tools/ekg_train.c`

### Modify `write_best_config_header()` (lines 933-998)
